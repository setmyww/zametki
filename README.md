# Заметки

Быстрые заметки и списки дел для Windows.

## Установка

* Через **Nexus Launcher** — найдите «Заметки» в каталоге и нажмите «Установить».
* Вручную — скачайте `Zametki-Setup-x.y.z.exe` из [последнего релиза](../../releases/latest) и запустите.

Обновления выходят в разделе [Releases](../../releases); лаунчер сообщает о них автоматически.

## Разработка

```sh
npm install
npm run dev
```

Проверка JavaScript: `npm run check`. Сборка Windows-установщика: `npm run dist`.

Доски сохраняются локально вместе с заметками. На холсте можно добавлять стикеры, текст и фигуры, перемещать элементы, менять цвета и связывать идеи.
